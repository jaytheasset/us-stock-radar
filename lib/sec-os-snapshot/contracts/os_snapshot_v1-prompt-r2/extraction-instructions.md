# O/S Snapshot v1 — single extraction, prompt-r2

Use only the assigned SEC source package, official filing metadata and frozen os_snapshot_v1 schema. One GPT extraction per filing; no independent extractor, reviewer, controller reassessment, retry or external API. Do not read previous outputs, evaluation records, expected values/statuses or other filings' results. GPT alone judges meaning. Tools may navigate/read neutral blocks and check hashes/JSON structure; they must not select, compute, correct or supplement semantic values.

Select the most recent directly stated current actual ordinary/common outstanding stage in the prospectus/amendment or share-capital description. Capitalization and financial statement/share-capital-note figures are fallback only when no direct current prospectus/share-capital O/S exists. A current genuine conflict must not be hidden by selecting an older financial statement. Preserve each directly stated actual ordinary/common total and each directly stated actual class at the selected stage. Classes without a stated total suffice; never sum them. A preferred-inclusive aggregate does not invalidate separately identifiable ordinary class counts.

Different numbers with the same date are not automatically a conflict. GPT must check whether they have the same current stage, issuer scope and inclusion basis. Read the adjacent inclusion/exclusion explanation: one amount may include restricted or treasury shares whereas an accounting presentation excludes them. Check whether a direct current prospectus/share-capital outstanding total exists and whether other amounts are separate capitalization/financial accounting presentations. If the direct current share-capital O/S exists and differences are explained by inclusion/accounting presentation, select the directly stated current share-capital O/S as PASS. Do not output component balances or fallback accounting amounts as additional current snapshot stages. Do not calculate differences to verify or repair them. CONFLICTING_CURRENT_OS requires the same current stage, issuer scope and inclusion basis, different directly stated actual quantities, and no source inclusion/exclusion explanation resolving the difference. Preserve genuine contradictory current assertions even if one resembles an offering scenario elsewhere; do not silently correct the source.

Only directly stated outstanding or issued-and-outstanding ordinary/common quantities qualify. Exclude authorized, registered, reserved, issuable, offered, post-offering, pro forma/adjusted, assumed conversion/exercise, preferred, options/warrants/RSUs/pools, treasury/restricted components, ADS counts/ratios/equivalents, historical opening/closing/comparative balances, EPS averages and individual holdings. No Offering, ADS, corporate-action or historical-inventory analysis/output.

Read the cover, current outstanding summary, share-capital description, and as needed capitalization actual column, latest balance-share caption and latest share-capital note. Read headings, cells and immediately relevant footnotes/continuations together. Search only locates text. If a tool truncates current context, read its adjacent continuation. Do not audit every historical table. No coverage JSON or read-log gate.

Record scope issuer_total with share_class=null, or scope class with its exact source class label. Quantity is a directly stated integer string. as_of_date is a directly supported calendar date or null; preserve the source date expression in as_of_text. Filing date is never automatic observation date. A source 'as of this prospectus' expression may connect to its explicitly dated cover; cite both blocks. Read the complete chosen blocks before submitting. Do not add field-level wrappers, evidence graph, basis_detail, coverage fields or long explanations.

Use only PASS (nonempty current_os, review=null), REVIEW_REQUIRED (current_os=[], review with code/candidates), or NO_DIRECT_CURRENT_OS (current_os=[], review=null). Retain all genuine conflict candidates; never choose or repair one. The latter two codes may have an empty candidate array if no honest record can be expressed.
