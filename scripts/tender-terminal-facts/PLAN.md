# Tender terminal FACT experiments

Base c36f5cbf54f8d5d70d2781717c1aeb8c2eaa2a68, existing detached candidate worktree only.

Order: offer_status 5 cases; only after Practical PASS prepare final_results_observed 3–5 cases. STOP after those experiments. No union, product changes, DB, UI, jobs, push or deployment.

One physical gemini-3.5-flash call per case per FACT. No retry, repair, fallback or semantic postprocessing. Freeze source/projection/map/prompt/schema/exact request/hash/run identity before fetch; exclusive started marker. Interrupted started runs remain consumed. Expected answers are confined to manifest and audits, never provider input. Shared existing callOnce and Evidence implementation are imported unchanged.

Before each batch, direct SEC source review defines coverage and expected sparse semantics. After each call, Codex compares raw structured output to the selected source and explicitly classifies every cited ref. This is Codex review, NOT independent human signoff. Any semantic/contract failure stops the batch and blocks the next FACT. Technical/source failures are also reported without another call.

Status contract: one actual tender-level withdrawn/terminated observation. Explicit withdrawal wins when that same event is also called termination; this is a pre-call representational choice, not an output repair. Rights, hypothetical/future termination, shareholder withdrawal, expiration and successful completion are excluded. Normal absence returns empty facts AND empty unresolved. Material source uncertainty alone uses unresolved. No dates, previous, reason or change fields.

Call purposes: Jos tests explicit withdrawal with synonymous termination and competing transaction context; Blue Wolf tests actual tender termination versus future merger termination; Rumble tests rights-only abstention; Carlyle tests final/expired/accepted-share abstention; Xerox tests third-party amendment termination. Each ends after one response or transport failure, with preserved raw output and separate schema/provenance/meaning judgments. PASS requires all five technically and semantically correct, direct support for each claim, no irrelevant/conflicting/foreign refs, and no invented status.

Failure classes: SOURCE_COVERAGE, MODEL_ERROR, SCHEMA_ERROR, SOURCE_UNRESOLVED, PROVIDER_MODEL_UNAVAILABLE, PREFLIGHT_TEST_ERROR. No model error may be hidden by expanding source after calling. Reused source artifacts are allowed; prior model outputs are never meaning evidence.
